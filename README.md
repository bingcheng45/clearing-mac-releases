# Clearing

Clearing frees disk space that Xcode and coding agents leave behind on your Mac. It finds idle iOS simulators, stale git worktrees and build caches, shows what each one holds, and cleans them on a schedule you set.

## Download

Get the latest `Clearing-x.y.z.zip` from [Releases](https://github.com/bingcheng45/clearing-mac-releases/releases/latest). Unzip it and drag Clearing to Applications. It needs macOS 15 or later.

Clearing is free for 7 days with every feature. After that, a license key unlocks it. Installed copies update themselves.

## About this repository

This repository holds only signed releases and the update feed (`appcast.xml`). The source code is private.
